# 食刻 App · 页面设计 v1.1

> 2026-11-06 · 平台：Android / iOS（C 端用户 App）
> 依据：现有数据层（`ingredient` / `dish` 表、节气词表、当前节气 ±2 当令推荐口径）+ 菜品流水线（健康厨师/校验双 Agent）。
> 内部审核台维持 Web 版（`web/review.html`），不在本套设计范围。
> **v1.1**（反馈"风格过于朴素"后升级）：封面级深色 Hero、朱砂印章、食签牌视觉锚点、菜品封面横幅、四季渐变横幅、热量环、悬浮 Dock；信息架构与 AA 对比度底线不变。

## 如何查看

浏览器打开 `index.html`（画廊，含全部画面缩略预览），点击任意画面进入可交互原型。
页面间链接可真实点击跳转（底部 4 Tab、首页 Hero → 全年节气、列表 → 详情）。
最佳观看宽度 390px+；窗口 ≤480px 时自动全屏（模拟真机）。

## 导航结构

```
底部 4 Tab（一级）
├─ 今日 home.html
│   ├─ → 全年节气 terms.html（push）
│   ├─ → 食材详情 ingredient-detail.html（push）
│   └─ → 菜品详情 dish-detail.html（push）/ 菜谱库 recipes.html
├─ 菜谱 recipes.html
│   └─ → 菜品详情 dish-detail.html（push）
├─ 食材 ingredients.html
│   └─ → 食材详情 ingredient-detail.html（push）
└─ 我的 mine.html
```

- 详情页均为 push 页：返回按钮 + 无底部 Tab；深链规划 `shike://dish/{name}`、`shike://ingredient/{name}`、`shike://term/{name}`。
- C 端只呈现「已通过」内容；`status` 三态仅存在于内部审核台，App 内不出现审核态。

## 设计系统速览

完整规范见 [DESIGN-SYSTEM.md](DESIGN-SYSTEM.md)。核心一句话：**新中式雅致 —— 宣纸底、墨色字、四季点彩、朱砂印章点睛、封面级深浅节奏**。

- **中性层**：宣纸 `#F6F2E9` / 墨 `#26231C`（14.0:1）/ 次级 `#5B564A`（6.5:1）/ 辅助 `#6E6858`（仅 ≥13px）
- **四季点彩**（accent 随当前节气季节切换，原型为冬·黛 `#2E4A66`）：春青 `#37714A` · 夏朱 `#B5432C` · 秋赭 `#8A5D15` · 冬黛 `#2E4A66`，每季配深档（渐变终点/深字）与淡底；白字全部 ≥4.5:1
- **v1.1 品牌元件**：朱砂印章 `.seal`（`#B03A2E`，白字 6.0:1）、食签牌 `.mono`（季色渐变 + 衬线白字首字，替代照片位）、菜品封面横幅、热量环（琥珀金弧）、悬浮毛玻璃 Dock
- **四气徽章**（功能信息色+字双编码）：寒→热 七档冷/中/暖色阶；五味为中性描边 chip（克制不彩虹）
- **字体**：Noto Serif SC / Songti SC（节气名、菜名、封面字、典籍引文）× PingFang SC / Noto Sans SC（正文），热量/分量用 tabular-nums
- **风格来源**：ui-ux-pro-max 检索两轮收敛 —— 版式取 Minimalism & Swiss 骨架，字体对取 Noto Serif/Sans（中文文化内容），配色未采纳脚本建议（Claymorphism 玩具感、玫粉强调色与产品气质不符），按语义 Token 框架本地化为四季色；v1.1 依用户反馈增强视觉表现力

## 与后端功能的映射

| 现有功能/字段 | App 呈现 |
|---|---|
| 节气词表（24）+ 当前 ±2 推荐口径 | 今日 Hero 当令带、菜谱/食材默认筛选、全年节气页 |
| `ingredient`（四气/五味/归经/功效/季节/caution/classic_note） | 食材百科 + 食材详情（徽章、归经行、引文卡） |
| `dish`（category/主料定量/steps/calories/benefits/caution/style/solar_terms） | 菜谱库 + 菜品详情（定量表、时间线、双角度好处、忌口） |
| 「健康厨师」出品标识 | 菜品卡/详情的「健康厨师」徽章（为「美食大厨」预留同位徽章） |
| 词表封闭值域 | 全部筛选 chip 的取值即词表值，不自造 |

## 声明与后续

- **示例数据**：原型中的食材档案、菜谱、典籍引文均为设计占位，值域对齐词表但未经考据审定；上线内容以流水线 + 审核台产出为准。
- **v1 不做**：暗色模式（Token 已预留映射方案）、账号体系、社区/评论、视频步骤。
- **预留扩展**：「美食大厨」菜品徽章、菜品详情「开始烹饪」全屏步骤模式、入节提醒推送、偏好参与菜谱排序。
