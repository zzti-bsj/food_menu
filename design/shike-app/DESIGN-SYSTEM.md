## 1. 产品与风格定位

- **产品**：食刻 —— 二十四节气 × 顺时饮食。C 端：今日节气 / 当令推荐 / 应季菜谱（未登录可浏览官方库）；**工坊**（数据主理人）：三条 LLM 流水线（食材批量 / 健康厨师 / 美食大厨）的单件流转与三态审核；**账号体系**：手机号+密码（JWT access 2h / refresh 30 天），私有内容（user_id 非空）仅本人与 admin 可见（他人 404 防探测），官方库（user_id 为空）写操作仅 admin。
- **表单规范（v1.4）**：label 常显（必填 * 号）、输入即校验失焦报错、错误文案**逐字对齐接口**（如「手机号或密码不正确」「手机号已注册：138…」role=alert）、密码带可见性切换（支持粘贴/密码管理器）、helper 说明规则（≥6 位等）。
- **「我的」范式（v1.4.3）**：导航中枢而非内容堆叠——资料头部（头像+昵称+角色，点按进编辑资料）+ 入口列表行（icon + 标题 + 副文案 + 计数/徽章 + chevron）；通用偏好/关于/退出登录归设置页；修改密码入口归登录页「忘记密码」（未登录找回接口待补）。
- **风格**：**新中式 × 青春活力**（v1.2）—— 亮纸底、墨色字、四季明彩、朱砂印章点睛；大面积**粉彩渐变面板**（蓝绿→青瓷→奶油）承载节气/菜品/食材封面，配合贴纸与星光涂鸦， youthful 而不失去文化骨架。
- **气质关键词**：时令、清新、元气、考究（文化骨架不变，表达更年轻）。
- **反模式（不做）**：玩具感拟物、彩虹乱用（色彩仍按四季语义分配）、emoji 图标、营销渐变堆砌。

### 2.6 粉彩面板（`.panel-pop`，v1.2 核心语言）

- 冬（当前季）：`135deg #E4F1FB → #DFF0E9 → #FFF6E2`（蓝→青瓷→奶油）；春/夏/秋各有同构粉彩渐变。

### 2.7 暗色模式

v1 不做暗色。规划：暗色下粉彩面板换为深色玻璃拟态（墨绿/黛蓝深底 + 白字），逐 Token 映射单独验证。

## 3. 字体

| 角色 | Token | 字族 | 字号/行高 | 用途 |
|---|---|---|---|---|
| 展示 | `--font-display` | Noto Serif SC / Songti SC（衬线） | 28–30/40 · 66(节气 Hero) | 节气名、页面大标题、菜名、封面字 |
| 组标签 | `--font-body` | 无衬线 600 | 13/18 · 字距 1px · `--ink-3` | 小节标题（v1.4.2 由 20px 衬线降级；不含菱点装饰） |
| 正文强调 | `--font-body` | PingFang SC / Noto Sans SC 600 | 17/24 | 列表主文字 |
| 正文 | `--font-body` | 400 | 15/23 | 正文、列表描述 |
| 注脚 | `--font-body` | 400 | 13/18 | 说明、元信息（下限 13px） |
| 导航标签 | `--font-body` | 500 | 11/14 | 底部 Dock |

- 正文行高 1.5+，行长 ≤ 42 字（移动端）。
- 数字（热量、分量、时间）用 `font-variant-numeric: tabular-nums`。
- 典籍引文一律衬线 + 「引」字水印（"引文脸"）。
- 活力感表达优先靠色彩/图形/贴纸，**不靠字体变形**（衬线骨架保持文化识别）。

## 4. 间距 / 圆角 / 阴影 / 层级

- **间距**（4pt 基准）：`--s1:4 · --s2:8 · --s3:12 · --s4:16 · --s5:20 · --s6:24 · --s8:32`
- 页面左右边距 20px；区块间 24–32px；卡片内边距 16px。
- **圆角**：`--r-s:10` · `--r-m:16` · `--r-l:24`；Dock 26；印章 8（斜贴 -3°）。
- **阴影三档**：卡片 `--shadow-card`；抬起 `--shadow-lift`；浮层 `--shadow-float`。彩色元件用同色投影（签牌/贴纸/主按钮/步骤序号）。
- **z-index**：内容 0 / 吸顶头 10 / Dock·操作条 20 / 弹层 40 / Toast 100

## 5. 图标

- 单一图标族：**线性 SVG**（Phosphor 风格），1.8px 描边、圆头圆角、24 viewBox，统一 `currentColor`。
- 涂鸦例外：星光 `.sparkle`（填充四角星）、波浪 `.squiggle`（2.2px 波浪线）——手绘感点缀，装饰性 `aria-hidden`。
- 全部 `aria-hidden="true"`（旁有文字时）；独占按钮必须带 `aria-label`；**禁止 emoji 作结构性图标**。

## 8. 页面结构与导航

- **框架**：状态栏 → 可滚动内容 → **悬浮 Dock**（内容区预留下垫 122px）。
- **一级导航（Dock 5 Tab）**：今日 / 菜谱 / 食材 / **工坊** / 我的。二级页面（节气总览、详情页、工坊流水线与审核页）push + 返回，不进 Tab。
- **深层可达**：`shike://dish/{name}`、`shike://ingredient/{name}`、`shike://term/{name}`、`shike://review/{id}`。
- **安全区**：顶部状态栏 47、底部 Home 指示区 34；Dock 与吸底操作条不遮挡滚动内容。
- **工坊审核操作栏**：吸底双按钮 ——「驳回」（danger 淡底描边）+「通过」（主按钮），对应 `POST /api/status`、`POST /api/dish/status`。

## 9. 可访问性底线（CRITICAL）

1. 文字对比 ≥4.5:1；大字与纯装饰 ≥3:1（签牌字为装饰性 aria-hidden 大字，白字对渐变起点 <3 不作信息载体，名称由相邻文字承载）。
2. 触控目标 ≥44×44，间距 ≥8。
3. 不依赖颜色单独传义（四气徽章色+文字、忌口=图标+文字）。
4. 焦点可见（`focus-visible` 2px accent 描边），Tab 顺序=视觉顺序。
5. 标题层级 h1→h2 顺序；图标按钮必有 `aria-label`；签牌/印章/贴纸/涂鸦全部 `aria-hidden`。
6. `prefers-reduced-motion` 全局降级（星光缓浮动画停用）。
7. 支持系统字号放大：弹性布局，换行优先不截断。
