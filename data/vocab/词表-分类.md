# 词表 · 分类(15 大类)

> 用途:`ingredient.category` 的值域。**大类可多选**(1–3 个,半角逗号分隔),解决跨类归属——如薏米 = `谷类,药食两用`,山药 = `薯芋,药食两用`。
> 子类仅作理解边界的参考,**暂不落库**;将来启用时给表加一列即可。

参照《中国食物成分表》21 大类体系裁剪而成,砍掉婴幼儿食品、速食食品、小吃甜饼等家常做饭用不到的类。

| 大类     | 子类(参考,暂不落库)                |
| ------ | -------------------------- |
| 谷类     | 米、面、杂粮                     |
| 薯芋     | 薯、芋                        |
| 干豆与豆制品 | 干豆、豆制品                     |
| 蔬菜     | 叶花菜、根菜、茄果、瓜菜、葱蒜、水生蔬菜、鲜豆、野菜 |
| 菌藻     | 菌类、藻类                      |
| 水果     | 仁果、核果、浆果、柑橘、瓜果、热带水果、干果     |
| 坚果种子   | 坚果、种子                      |
| 畜肉     | 猪、牛、羊、畜杂                   |
| 禽肉     | 鸡、鸭鹅、禽杂                    |
| 蛋类     | 鲜蛋、再制蛋                     |
| 水产     | 淡水鱼、海水鱼、虾、蟹、贝、头足           |
| 乳类     | 奶、酸奶、奶酪                    |
| 油脂     | 植物油、动物油                    |
| 调味品    | 香辛料、发酵调料、糖蜜                |
| 药食两用   | 枸杞、菊花、百合、莲子、芡实等(按药食同源目录)   |
